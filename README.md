# 個人資料表、PSQI 與 HAMD

這是一個可放在 GitHub Pages（`github.io`）的靜態網站。首頁填寫個人資料表，再進入 PSQI 與 HAMD。三份表單各自儲存在目前瀏覽器中，可依患者編號與填寫次數回看，並分別輸出 Excel 或 PDF。

## 個人資料表與導覽

首頁依提供的兩頁 PDF 填寫基本資料、吸菸、飲酒、咖啡因、視聽與行動狀態、過去病史及用藥。教育程度使用指定的八項下拉選單；吸菸、飲酒、咖啡因、視聽、行動及憂鬱症就醫狀態可點選按鈕；茶的攝取量以杯／天填寫。Date 預設今天；患者編號與第 1–5 次填寫次數用於辨識紀錄。儲存後可點清單中的患者編號回看與更新，也可逐筆輸出已填妥的 PDF。用藥較多時會自動加頁，不截斷內容。

導覽順序為 **個人資料表 → PSQI → HAMD**；PSQI 可返回個人資料表，HAMD 可返回 PSQI。三頁共用同一網站來源的瀏覽器儲存空間；不同裝置不會同步。

個人資料表可逐筆輸出 PDF；PSQI 和 HAMD 可匯出已儲存紀錄的 Excel，也可逐筆輸出 PDF。原始填答紀錄只存於目前裝置的瀏覽器，不會在不同裝置間同步。

## 群暉 NAS 上傳

網站可以繼續放在 GitHub Pages，原本 iPad 內的紀錄不必搬移。在群暉 Web Station 部署 `nas-upload.php` 並設定 PHP 與私人儲存資料夾後，個人資料、PSQI、HAMD 三頁都會顯示「上傳至 NAS」按鈕。從任一頁按下並輸入上傳密碼，會直接上傳三頁已儲存紀錄的一份 PSQI／HAMD Excel 和各份 PDF，不會壓縮。部署請依 [NAS 設定說明](nas-setup/README.md)。

## 發布到 GitHub Pages

1. 在 GitHub 建立**公開**儲存庫，例如 `psqi-calculator`。
2. 將此資料夾中的網站檔案上傳到儲存庫**根目錄**，保留 `vendor` 資料夾及其檔案，並提交變更。`README.md` 也可以一起上傳。
3. 開啟儲存庫 **Settings → Pages**。在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`，資料夾選 `/ (root)`，儲存。
4. 等待 GitHub 顯示網站網址。若帳號為 `USERNAME`、儲存庫為 `psqi-calculator`，網址通常是 `https://USERNAME.github.io/psqi-calculator/`。

參考：[GitHub Pages 官方發布說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## HAMD 漢彌頓憂鬱量表

從 `Psqi.html` 上方的「HAMD 憂鬱量表」進入 `Hamd.html`。題目、訪談提問及選項依使用者提供的《HAMD漢彌頓.pdf》整理，共 21 項；第 16 項體重減輕先選 A（病史）或 B（每週體重測量），只計一次。全部選完後按「計算總分」，21 項分數直接相加。

結果頁只顯示 **21 項總分**，不顯示憂鬱程度或分級。可填寫 Date、患者編號及選填的 Time（1–5）；患者編號保持原樣，Time 另存於 Excel。每題可填選填備註，匯出時接在分數後，例如 `2(備註)`。第 16 題仍只計所選 A 或 B 的一個分數。

HAMD 表單操作區固定顯示「輸出表單」按鈕：尚未儲存時不可使用；只有一筆已儲存紀錄時直接下載，多筆時會跳到下方清單供逐筆選擇。

每位完成後按「儲存當前分數」，可連續記錄多位患者。已儲存清單中的藍色患者編號可將原本的 21 題勾選、備註、日期與次別帶回上方量表；修改後按「更新此患者紀錄」會更新原筆，按「取消回看，填下一位」可清空表單。已儲存紀錄依患者編號及 Time 排序，可逐筆刪除、逐筆按「輸出表單」下載 HAMD PDF，或清除全部；「匯出 Excel」只包含已儲存紀錄，輸出 Date、ID、Time、21 題和 Total，共 25 欄，與提供的 HAMD 表格欄位順序相同。PDF 會在選定的分數旁打勾，最後一頁顯示總分；有備註時會附加備註頁。第 16 題的 A／B 評分方式會隨新紀錄儲存；舊紀錄若未保存該方式，回看時需先補選 A 或 B，PDF 也會註明而不猜測。

## 填答及 Excel

- 操作按鈕分為兩列：**計算分數／清除全部紀錄**、**儲存患者紀錄／匯出 Excel**。每位填完後先儲存，表單會清空供下一位填答；點擊已儲存清單中的藍色患者編號，可將原本勾選的選項、藥物與備註帶回上方問卷，修改後按「更新此患者紀錄」會更新原紀錄；按「取消回看，填下一位」可清空表單而不改動原紀錄。全部完成後按「匯出 Excel」，每人輸出一列。Excel 只包含已儲存紀錄。按「計算分數」只預覽目前分數，**不會**自動加入清單。
- 紀錄儲存在目前裝置的瀏覽器中，重新整理後仍會保留；不同裝置、瀏覽器之間不會同步。可逐筆刪除或清除全部紀錄。
- 已儲存清單與匯出的 Excel 依患者編號排序（例如 `CD4` 在 `CD5` 前、`CD2` 在 `CD10` 前）；同一患者依次別 1–5 排列。未填患者編號的紀錄排在最後，並維持原儲存順序。既有紀錄重新開啟網頁後也會套用排序。
- `Date` 預設為開啟網頁當天，填答者可自行改選；旁邊的患者編號為選填，匯出後寫入 Excel 的 `ID` 欄，前導零會保留。編號下方的 1–5 次別按鈕亦為選填；例如輸入 `ABC123` 後按 1，患者編號仍為 `ABC123`，Excel 的 `ID` 為 `ABC123`、`Time` 為數字 `1`。再按一次已選的按鈕可取消次別，未選時 `Time` 留白。先前儲存且由舊版自動加上 ` -1`、` -2`、` -3` 的編號，重新開啟時會移除該尾碼。
- 上床與起床時間各有「時：分」兩格；每一格都能直接鍵入數字，或按箭頭從下拉清單選擇。使用 24 小時制，例如下午 1 點為 `13:00`。
- Excel 有 35 欄：日期、ID、Time、第 1–9 題答案、第 7 題後的三個藥物類別欄及用藥備註欄、七個構面分數、睡眠效率百分比及總分。第 6–9 題依原始 PDF 題序輸出：睡眠品質、用藥、日間瞌睡、無心完成事情。第 10 題不提供填答，也不輸出至 Excel；舊紀錄的第 10 題答案仍保存在瀏覽器內，但不會顯示或匯出。睡眠效率欄位位於 `PSQI Score` 前，為可計算的百分比數值。
- 按「計算分數」後才會顯示圓餅圖，呈現七個構面各占當次總分的比例；滑鼠移到扇形可查看構面名稱。睡眠效率顯示在七個構面下方，不納入圓餅圖。每個圓餅圖百分比以構面分數除以當次總分計算。總分為 0 時不顯示比例。
- 第 5j 題可略過；計分時視為 0 分，Excel 原始答案欄保留空白。
- 第 5a–5j 題及第 6、8、9 題都有選填備註。填寫後，Excel 的該題答案欄會顯示如 `0(因為某某疾病)`；計分仍只使用原本的數字答案。若 5j 僅填備註而未選頻率，Excel 顯示 `0(備註)`。
- 第 7 題有鎮定安眠藥、抗精神藥物、抗憂鬱藥物三個選填欄位；共用備註框位於這三欄外的右下角。輸入藥名時會顯示可選的完整文字，Agomelatine、Fluvoxamine、Chlorpromazine、Brexpiprazole、Estazolam、Zolpidem、Zopiclone、Flunitrazepam、Lemborexant、Ramelteon 依提供的表格列出多種劑量、用法與單位格式；選取後仍可直接修改內容，QID 等其他用法與「顆／粒／錠／片」也可自行輸入。若在其他類別欄搜尋到這些藥名，選取時會填入其所屬類別欄。同類多種藥物用 `；` 分隔。三類藥物與用藥備註分別輸出至 Excel 的獨立欄位，並列在 PDF 備註頁，不影響第 7 題計分。舊紀錄原有的用藥備註仍保留在第 7 題答案欄和 PDF 備註頁，點開舊紀錄時會帶入新的備註框。
- Excel 在瀏覽器產生並下載。填答紀錄只存放在目前瀏覽器的本機儲存空間；只有主動按「上傳至 NAS」並輸入密碼時，產生的 Excel／PDF 才會傳到 NAS。

## 輸出已填寫的 PSQI 表單

PSQI 表單操作區也固定顯示「輸出表單」按鈕，操作方式與 HAMD 相同。

填完目前患者後，先按「儲存患者紀錄」，再於下方該筆紀錄按「輸出表單」，即可**個別下載**標記過的 PDF。第 1、2、3、4 題會填入時間或數字；第 5a–5j 題及後續選項會在原表對應的方框內打勾。第 4 題若輸入小數時數，會換算成小時與分鐘，例如 6.5 小時填為 6 時 30 分。

網頁、Excel 與 PDF 的第 6–9 題均依原始表單排序；先前在此瀏覽器儲存的紀錄也會以正確題序匯出。PDF 原表第 10 題保持空白。下載的 PDF **只保留原表第一頁**；有選填備註時，會另附不標示「PDF 第幾題」的備註頁。表單在目前瀏覽器製作，不會上傳患者填答。

## 本工具的計分規則

| 構面 | 算法 |
| --- | --- |
| C1 主觀睡眠品質 | 第 6 題，0–3 分 |
| C2 睡眠潛伏期 | 第 2 題分鐘數：≤15→0、16–30→1、31–60→2、>60→3；加上第 5a 題後，總和 0→0、1–2→1、3–4→2、5–6→3 |
| C3 睡眠時數 | 第 4 題：≥7 小時→0、6–<7→1、5–<6→2、<5→3 |
| C4 睡眠效率 | 第 4 題睡眠時數 ÷（第 1 題上床至第 3 題起床的時間）×100%；≥85%→0、75–<85%→1、65–<75%→2、<65%→3 |
| C5 睡眠困擾 | 第 5b–5j 題相加：0→0、1–9→1、10–18→2、19–27→3 |
| C6 安眠藥物使用 | 第 7 題，0–3 分 |
| C7 日間功能障礙 | **維持本專案既有算法：第 9 題（無心完成事情）＋第 6 題（睡眠品質）**，總和 0→0、1–2→1、3–4→2、5–6→3 |

七個構面相加為 0–21 分。第 8 題保留原始答案並匯出，但**不參與本工具的計分**。C7 沿用本專案先前的算法，與[原版 PSQI 計分說明](https://www.sleep.pitt.edu/psqi)不同；若要用於正式研究，應先確認採用的問卷版本與計分規則。
