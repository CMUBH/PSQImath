# PSQI 睡眠品質計算機

這是一個可放在 GitHub Pages（`github.io`）的靜態網站。可連續填寫多人的 PSQI 問卷，將每位結果加入瀏覽器中的紀錄清單，最後匯出同一份 Excel；不需要 Python、資料庫或後端伺服器。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁與問卷 |
| `style.css` | 網頁樣式 |
| `app.js` | 計分與 Excel 匯出 |
| `.nojekyll` | 告訴 GitHub Pages 直接提供靜態檔案 |

在電腦上直接開啟 `index.html`，即可先試用。四個網站檔案需保持在同一層目錄。

## 發布到 GitHub Pages

1. 在 GitHub 建立**公開**儲存庫，例如 `psqi-calculator`。
2. 將此資料夾的 `index.html`、`style.css`、`app.js`、`.nojekyll` 上傳到儲存庫**根目錄**，並提交變更。`README.md` 也可以一起上傳。
3. 開啟儲存庫 **Settings → Pages**。在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`，資料夾選 `/ (root)`，儲存。
4. 等待 GitHub 顯示網站網址。若帳號為 `USERNAME`、儲存庫為 `psqi-calculator`，網址通常是 `https://USERNAME.github.io/psqi-calculator/`。

參考：[GitHub Pages 官方發布說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 填答及 Excel

- 操作按鈕分為兩列：**計算分數／清除全部紀錄**、**儲存當前分數／匯出 Excel**。每位填完後按「儲存當前分數」，表單會清空供下一位填答；全部完成後按「匯出 Excel」，每人輸出一列。按「計算分數」只預覽目前分數，**不會**自動加入清單。
- 紀錄儲存在目前裝置的瀏覽器中，重新整理後仍會保留；不同裝置、瀏覽器之間不會同步。可逐筆刪除或清除全部紀錄。
- `Date` 預設為開啟網頁當天，填答者可自行改選；旁邊的患者編號為選填，匯出後寫入 Excel 的 `ID` 欄，前導零會保留。`Time` 在 Excel 留白，供下載後自行輸入。
- 上床與起床時間各有「時：分」兩格；每一格都能直接鍵入數字，或按箭頭從下拉清單選擇。使用 24 小時制，例如下午 1 點為 `13:00`。
- Excel 有 31 欄：日期、ID、Time、各題答案、七個構面分數、睡眠效率百分比及總分。睡眠效率欄位位於 `PSQI Score` 前，為可計算的百分比數值。
- 按「計算分數」後才會顯示圓餅圖，呈現七個構面各占當次總分的比例；滑鼠移到扇形可查看構面名稱。睡眠效率顯示在七個構面下方，不納入圓餅圖。每個圓餅圖百分比以構面分數除以當次總分計算。總分為 0 時不顯示比例。
- 第 5j 題可略過；計分時視為 0 分，Excel 原始答案欄保留空白。
- 第 5a–5j 題及第 6–9 題都有選填備註。填寫後，Excel 的該題答案欄會顯示如 `0(因為某某疾病)`；計分仍只使用原本的數字答案。若 5j 僅填備註而未選頻率，Excel 顯示 `0(備註)`。
- 第 6 題備註可從「鎮定安眠藥」、「抗精神藥物」、「抗憂鬱藥」選擇，也可自行輸入；匯出時會附在 Excel 的第 6 題答案後。
- Excel 在瀏覽器產生並下載。填答紀錄只存放在目前瀏覽器的本機儲存空間，不會傳到網站伺服器。

## 本工具的計分規則

| 構面 | 算法 |
| --- | --- |
| C1 主觀睡眠品質 | 第 9 題，0–3 分 |
| C2 睡眠潛伏期 | 第 2 題分鐘數：≤15→0、16–30→1、31–60→2、>60→3；加上第 5a 題後，總和 0→0、1–2→1、3–4→2、5–6→3 |
| C3 睡眠時數 | 第 4 題：≥7 小時→0、6–<7→1、5–<6→2、<5→3 |
| C4 睡眠效率 | 第 4 題睡眠時數 ÷（第 1 題上床至第 3 題起床的時間）×100%；≥85%→0、75–<85%→1、65–<75%→2、<65%→3 |
| C5 睡眠困擾 | 第 5b–5j 題相加：0→0、1–9→1、10–18→2、19–27→3 |
| C6 安眠藥物使用 | 第 6 題，0–3 分 |
| C7 日間功能障礙 | **依本專案指定：第 8 題＋第 9 題**，總和 0→0、1–2→1、3–4→2、5–6→3 |

七個構面相加為 0–21 分。第 7 題保留原始答案並匯出，但**不參與本工具的計分**。這是本專案指定的題號與 C7 對應，與[原版 PSQI 計分說明](https://www.sleep.pitt.edu/psqi)不同；若要用於正式研究，應先確認採用的問卷版本與計分規則。
